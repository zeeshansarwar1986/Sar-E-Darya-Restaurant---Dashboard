# 🌴 Sar-E-Darya Restaurant Management Dashboard

Welcome to the **Sar-E-Darya Restaurant Management Dashboard**, a premium, offline-first management solution designed specifically for modern restaurant operations. This dashboard provides a sleek, efficient, and user-friendly interface to manage daily sales, stock, expenses, and employee wages in real-time.

![Sar-E-Darya Logo](logo.png)

## 🌟 Key Features

- **Direct Sales Entry**: Quickly enter lump-sum sales figures for the day.
- **Cash Denominations Counter**: Accurate tracking of physical cash (5000 to 10 PKR notes).
- **Stock Management**: Track incoming inventory with an option to deduct specific items from profit.
- **Expense Tracking**: Categorized expense management (Rent, Utility, Ration, etc.).
- **Daily Wages**: Record employee wages, advances, and extra payments.
- **Customizable Waiter Commission**: Adjustable percentage (1-10%) with a toggle to deduct from net profit.
- **Real-time Analytics**: Instant calculation of total sales, expenses, stock value, and net profit.
- **Premium Excel Export**: Generate professional, A4-landscape formatted reports using `ExcelJS`.
- **Auto-Save & Persistence**: Never lose data with automatic `localStorage` synchronization.
- **Khajoor (Date Palm) Theme**: A premium, earthy aesthetic inspired by the Sar-E-Darya brand.

## 🚀 Why Use This Dashboard?

1. **Efficiency**: Replaces messy paper logs with a structured digital system.
2. **Accuracy**: Automated calculations prevent human errors in profit reporting.
3. **Portability**: A single HTML file that runs on any modern web browser without needing a complex server.
4. **Professionalism**: Impress stakeholders with high-quality, printable Excel reports.
5. **Data Privacy**: All data is stored locally on your device; no cloud dependence.
